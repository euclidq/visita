# Visita

Visita is a web-based visitor management system designed to centralize the process of submitting, reviewing, approving, and monitoring visitor requests.

I built Visita to replace manual visitor logs with a clearer digital workflow. Visitors can submit and track registrations, while administrators can review requests and manage arrivals and departures from one dashboard. This project is created to strengthen my software quality assurance skills through hands-on testing across each release, including manual, API, and automated testing.

## Features

- Register a visit using a guided online form
- Verify visitor email addresses using a one-time password
- Generate a reference number for each registration
- Track a registration using its reference number and email address
- Send registration and status updates by email
- Secure administrator authentication
- View visitor activity and registration metrics
- Search, filter, sort, and paginate visitor registrations
- Approve or reject pending registrations with confirmation prompts
- Record rejection reasons and include them in visitor notifications
- Check approved visitors in and out
- Responsive desktop and mobile layouts

## How it works

1. A visitor enters their personal, and visit information.
2. Visita verifies the visitor's email address and creates the registration.
3. The visitor receives a reference number for tracking the registration.
4. An administrator reviews the request and approves or rejects it.
5. Visita notifies the visitor via email when the registration status changes.
6. Approved visitors can be checked in on arrival and checked out when they leave.
